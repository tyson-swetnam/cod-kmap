# NOTE: the JS parse check in scripts/qa.py no longer uses quickjs. quickjs
# cannot parse ES modules, so the check had to strip import/export lines with
# a regex before parsing — and that regex mis-handled multi-line imports,
# mangling the text it checked. It passed a file containing a live backtick
# bug, the exact defect it existed to catch. The check now shells out to
# `node --experimental-vm-modules` and parses each file AS WRITTEN via
# vm.SourceTextModule. Node is not a Python dependency and not a build step:
# nothing in src/ is compiled, bundled or transpiled, and the site still loads
# plain ES modules from an importmap. qa.py skips the check with a warning if
# node is absent.
