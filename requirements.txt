# NOTE: the JS parse check in scripts/qa.py no longer uses quickjs. quickjs
# DID catch the syntax errors it was added for — but it has no ES-module
# parser, so the check had to blank out import/export lines and wrap the rest
# in a function expression, and a failure then surfaced as "SyntaxError:
# expecting '}'" against the wrapper, with no line number. Locating one cost a
# manual bisect. The check now shells out to `node --experimental-vm-modules`
# and parses each file AS WRITTEN via vm.SourceTextModule, which reports the
# real message at the real line. Node is not a Python dependency and not a
# build step: nothing in src/ is compiled, bundled or transpiled, and the site
# still loads plain ES modules from an importmap. qa.py skips the check with a
# warning if node is absent.
